# RV1126B Linux ARMHF support

RV1126B uses RKNN2 and Linux ARMv7 hard-float. This integration requires an
external RKNN Runtime 2.3.2 or newer; the bundled 2.2.0 runtime is not suitable.
The build checks the selected runtime version and preserves the existing
runtime selection for other Rockchip targets.

If a valid runtime library does not contain the optional embedded version
string, pass `-DISF_RKNN_RUNTIME_VERSION=2.3.2` (or the actual newer version)
to CMake explicitly.

## Build

Obtain the RKNN Runtime from the official RKNN-Toolkit2 SDK and expose its
`librknn_api` directory as `RKNN_RUNTIME_DIR`. The provided Dockerfile contains
the ARMHF cross-compilation environment.

```sh
docker build -f docker/Dockerfile.rv1126b -t inspireface-rv1126b .
docker run --rm -it -v "$PWD:/workspace" inspireface-rv1126b

export RKNN_RUNTIME_DIR=/rknn
bash command/build_cross_rv1126b_armhf.sh
```

The installed SDK is written below
`build/inspireface-linux-armhf-rv1126b/install/InspireFace`. Deploy
`libInspireFace.so` together with the selected `librknnrt.so`.

## Resource pack

Board tests consume a prebuilt RV1126B InspireFace resource pack supplied by
the caller. This repository does not convert, package, or publish model
weights. Pass the external pack to each launcher with `-PackPath`.

```powershell
command/rv1126b_public_api_e2e/run_board_capi_e2e.ps1 `
  -Serial <adb-serial> `
  -PackPath <path-to-prebuilt-rv1126b-pack>
```

The launchers calculate and record the pack SHA-256, transfer it to an isolated
board directory, verify round-trip integrity where applicable, and execute the
runtime scenarios. They do not require conversion inventory or reports.

## Image processing backends

CPU remains the default image-processing backend. RGA is an explicit opt-in
through `HFSwitchImageProcessingBackend(HF_IMAGE_PROCESSING_RGA)` after launch.
The tested board exposes `/dev/dma_heap/system-uncached` and
`/dev/dma_heap/system`; RV1126B selects those heaps without changing the
existing DMA32 heap selection used by other Rockchip targets.

The tested ARMHF `librga` version is 1.10.6. Verify the board driver and DMA
heap paths before enabling RGA on another image.

## Board validation

The following retained runners operate on an externally supplied pack:

- `rv1126b_public_api_e2e`: detection, no-face, landmarks, and recognition.
- `rv1126b_pipeline_matrix`: liveness, mask, quality, attributes, and emotion.
- `rv1126b_tracking_e2e`: single-face, multi-face, no-face, and landmark tracking.
- `rv1126b_capture_e2e`: face-capture state transitions.
- `rv1126b_stability_e2e`: repeated lifecycle and FeatureHub checks.
- `rv1126b_concurrent_e2e`: four concurrent sessions.
- `rv1126b_python_e2e`: generated ctypes bindings with an explicit ARMHF library.

Build scripts accept `SDK_INSTALL_DIR` pointing to the installed SDK. The
PowerShell launchers accept `RunnerDirectory`, `ResultDirectory`, and
`PackPath`, allowing build outputs and test evidence to remain outside Git.

## Verified environment

- Rockchip RV1126B XIAOYU 50IPC V10
- Linux ARMv7 hard-float
- RKNN API 2.3.2
- RKNN driver 0.9.8
- librga 1.10.6

The external test pack passed public API, optional pipeline, tracking, capture,
50-cycle CPU/RGA stability, four-session CPU/RGA concurrency, RGA DMA resize,
and Python ctypes smoke coverage. These results validate runtime integration;
they do not publish or define how the external model pack was produced.
